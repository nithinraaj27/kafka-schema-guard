🔌 How to Integrate Schema Guard

What is Schema Guard?

Schema Guard uses Spring Kafka's `ProducerPostProcessor` to intercept your messages before they reach the Kafka broker. If a payload doesn't strictly match the remote JSON schema, it throws a `SchemaValidationException` instantly, preventing Poison Pills from ever entering your data streams.

1. Add Maven Dependency

<dependency>
    <groupId>com.schemaguard</groupId>
    <artifactId>schema-guard-spring-boot-starter</artifactId>
    <version>1.0.0-SNAPSHOT</version>
</dependency>

2. Add to application.properties

schema-guard.enabled=true
schema-guard.registry-url=http://your-registry-api.com/schemas

# Map your Kafka topics to their respective schema IDs
schema-guard.topics.testing-events=your-schema-v1
schema-guard.topics.ledger-events=ledger-schema-v1

That's it! Zero code changes required in your Spring Boot application. It works entirely via Auto-Configuration.
