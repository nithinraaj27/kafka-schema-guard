# Schema Guard Live Tester UI

This is the interactive UI for testing the Schema Guard Spring Boot Starter.

## Deployment to Vercel

1.  **Install Vercel CLI** (optional):
    ```bash
    npm install -g vercel
    ```
2.  **Deploy**:
    From this directory, run:
    ```bash
    vercel
    ```
    Or connect this sub-folder in the Vercel Dashboard by selecting the `tester-ui` directory as the **Root Directory**.

## Build Commands
- **Framework Preset**: Vite
- **Build Command**: `npm run build`
- **Output Directory**: `dist`
